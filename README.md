# Atlas Interactivo de Cinesiterapia

Aplicación web interactiva que funciona como atlas de ejercicios de cinesiterapia, organizada por región anatómica y categoría terapéutica. Permite a docentes y administradores crear fichas detalladas de ejercicios (objetivo, indicaciones, contraindicaciones, dosificación, video e imágenes) y a estudiantes/usuarios consultarlas, comentarlas y buscarlas.

## Estado del proyecto
